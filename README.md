# 长篇小说写作台

一个面向长篇小说续写的本地工具。它可以导入已有 `.txt` / `.md` 小说，按章节切分，维护全书摘要和章节摘要，然后用这些信息组装上下文并调用 LLM 续写。

核心目标：不把整本书一次性丢给模型，而是稳定使用“全书摘要 + 最近原文 + 最近章节摘要 + 相关旧摘要”来续写。

## 启动

在项目目录运行：

```bash
python3 -m http.server 8080
```

浏览器打开：

```text
http://127.0.0.1:8080/
```

如果使用桌面版预览：

```bash
npm install
npm start
```

## 打包

打 Windows 安装包：

```bash
npm install
npm run dist:win
```

打 Windows 免安装便携版：

```bash
npm run dist:win:portable
```

构建结果会输出到 `dist/`。如果在 Linux 上打 Windows 包，需要本机已安装 Wine 等 `electron-builder` 依赖。

## 最短使用流程

必须做的步骤只有三个：

1. 在 **LLM 配置** 填好接口地址、模型和 API Key。
2. 在 **导入与预览** 导入小说，并先填写一版全书摘要。
3. 在 **续写** 选择当前章节，填写续写要求，点击 **生成续写**，满意后点击 **接受并追加**。

章节摘要、写作规则、新增章节标题、上下文高级预览都是可选功能。

## 1. 导入与预览

### 导入 TXT / MD

作用：把已有小说导入工具，并自动切成章节。

支持：

- `.txt`
- `.md`

切分规则：

- 优先识别 `第x章`、`第x回`、`Chapter x`、Markdown 标题。
- 如果识别不到章节，会自动按约 `6000-10000` 字切成伪章节。
- 导入只在本地完成，不会调用 LLM。

是否必须：必须。没有导入章节就不能续写。

### 全书摘要

作用：记录整本书当前推进到哪里，包括主线、矛盾、目标和伏笔。续写时会稳定进入上下文。

限制：最多 `2000` 字。

使用方式：

- 可以手动输入。
- 如果没有现成摘要，建议去 [DeepSeek Chat](https://chat.deepseek.com/) 上传或粘贴小说文本，让它生成一版全书摘要，再粘贴回来。
- 有了初始摘要后，可以点击 **AI 更新全书摘要** 做增量更新。

是否必须：强烈建议。没有全书摘要也能续写，但长篇一致性会差。

### AI 更新全书摘要

作用：调用你配置的 LLM，用“旧全书摘要 + 最近约 5000 字原文”生成新版全书摘要。

前提：必须已经有一版全书摘要。如果当前全书摘要为空，工具不会调用 LLM，会提示你先手动输入一版摘要。可以去 [DeepSeek Chat](https://chat.deepseek.com/) 上传小说文本生成初始摘要。

注意：

- 不会读取全文。
- 不会自动全文总结。
- 生成时可以点击 **中断**。
- 如果模型返回 `<think>...</think>`，这部分不会写入摘要。

是否必须：可选。你也可以完全手写全书摘要。

### 章节列表

作用：查看导入后的章节切分结果，点击某章可以编辑它的标题、摘要和正文。

是否必须：可选检查。导入后最好看一下切分是否合理。

### 当前章节

包含：

- 章节标题
- 章节摘要
- 章节正文

章节摘要的作用：续写时会优先使用最近章节摘要，帮助模型理解当前剧情承接。

是否必须：可选但建议补最近几章和关键章节。章节摘要越完整，模型越容易保持人物状态和剧情连续性。

### AI 生成章节摘要

作用：只把当前选中的章节发给 LLM，生成该章摘要。

摘要重点：

- 本章事件
- 人物状态变化
- 重要线索
- 伏笔
- 地点变化

是否必须：可选。也可以手写章节摘要。

### 放大编辑

每个主要文本框右上角都有放大按钮。

作用：打开大弹窗编辑长文本，适合改章节正文、摘要、续写要求和生成结果。

是否必须：可选。

## 2. 续写

### 当前章节

作用：指定续写发生的位置。

系统会从当前章节附近取最近原文，并结合全书摘要和章节摘要构建上下文。

是否必须：必须。

### 写入方式

有两种：

- **在原章节续写**：生成内容会追加到当前章节末尾。
- **新增一章**：生成内容会作为新章节正文，插入到当前章节后面。

如果选择新增一章，需要填写 **新章节标题**。

是否必须：必须选择一种，默认是“在原章节续写”。

### 本次续写要求

作用：告诉模型这次具体要写什么。

示例：

```text
从林舟发现玉佩发热开始，写他意识到青石镇旧案和玄都内鬼有关。节奏压迫，结尾留下沈月失踪的悬念。
```

是否必须：建议填写。留空也能生成，但模型方向会更不稳定。

### 写作规则

作用：放本次或长期的风格要求。

示例：

```text
第三人称近景，偏冷静克制。不要跳视角，不要提前揭晓幕后黑手。
```

是否必须：可选。

### 生成续写

作用：调用 LLM 生成正文。

生成时：

- 内容会流式显示在 **候选正文**。
- **生成续写** 会禁用，避免重复点击。
- 可以点击 **中断生成**。
- `<think>...</think>` 不会显示到候选正文里。

是否必须：如果你想让工具直接调用 LLM 续写，就是必须。也可以不用它，手动把别处生成的正文粘到候选正文。

### 候选正文

作用：暂存模型生成的内容。

这里的内容不会自动写入小说。你可以先修改，再点击接受。

是否必须：必须有内容才能接受写入。

### 接受并追加 / 接受并新增章节

作用：把候选正文写入小说。

- 原章节续写模式：追加到当前章节正文末尾。
- 新增一章模式：创建新章节，并把候选正文作为新章节正文。

是否必须：只有点击接受后，生成内容才会真正进入正文。

### 高级：本次使用的上下文

作用：查看本次会发给 LLM 的上下文。

里面包括：

- 全书摘要
- 最近原文范围
- 最近章节摘要
- 最终 Prompt

还可以复制 Prompt，拿到别的模型里手动生成。

是否必须：可选。主要用于排查模型为什么写偏，或手动调试 Prompt。

## 3. LLM 配置

### 接口地址

默认：

```text
https://api.deepseek.com/v1
```

要求：OpenAI 兼容的 `/chat/completions` 接口。

是否必须：必须。

### 模型

默认：

```text
deepseek-chat
```

如果使用其他兼容服务，填写对应模型名。

是否必须：必须。

### API Key

作用：调用模型接口的密钥。

当前是明文显示，并保存在浏览器本地 `localStorage`。

是否必须：必须。

### 温度

作用：控制生成随机性。

建议：

- `0.3-0.6`：摘要、梗概更稳。
- `0.7-1.0`：续写更有变化。

是否必须：可选，默认 `0.8`。

### 最大输出 Token

作用：限制模型一次最多输出多少。

默认：`1800`

是否必须：可选。

### 系统提示词

作用：给模型的全局写作身份和规则。

是否必须：可选。默认已经包含“只输出小说正文，不要解释”的要求。

## 数据保存

数据保存在当前浏览器本地：

- 导入的章节
- 全书摘要
- 章节摘要
- 正文修改
- LLM 配置
- 生成接受记录

手动修改全书摘要和章节摘要会即时保存。正文、章节和接受后的生成内容也会保存在当前浏览器本地。

如果需要拿到文件，可以点击左侧 **导出 TXT**。如果浏览器支持文件系统写入，也可以点击 **绑定写入 TXT** 授权一个 TXT 文件；授权后点击接受续写时，工具会把当前项目完整写入这个 TXT 文件。浏览器不能在未授权的情况下直接修改你导入时选择的原始文件。

如果需要删除当前项目，可以在 **导入与预览** 页底部打开 **危险操作**，点击 **清空当前项目**。清空会先弹出确认框，不会删除原始 TXT/MD 文件，也不会清空 LLM 配置。

注意：换浏览器、清理浏览器数据、换设备后，本地数据不会自动同步。

## 必须功能和可选功能

必须：

- 配置 LLM 接口、模型、API Key。
- 导入小说。
- 选择当前章节。
- 填写或维护全书摘要。
- 点击生成续写。
- 检查候选正文并接受写入。

建议但不强制：

- 检查章节切分。
- 给关键章节补章节摘要。
- 写清楚本次续写要求。

可选：

- AI 更新全书摘要。
- AI 生成章节摘要。
- 写作规则。
- 新增章节模式。
- 放大编辑。
- 高级上下文预览。
- 复制 Prompt 到外部模型。

## 常见问题

### 为什么导入后没有自动生成全书摘要？

为了避免 40 万字小说导入时产生高成本和不可控结果。导入只做本地切分。全书摘要需要先由你手写，或去 [DeepSeek Chat](https://chat.deepseek.com/) 上传/粘贴小说文本生成后再粘贴回来。之后可以点击 **AI 更新全书摘要** 按需增量更新。

### AI 更新全书摘要会读取全文吗？

不会。它只使用旧全书摘要和最近约 5000 字原文。如果旧全书摘要为空，工具会要求你先填写一版摘要。

### AI 生成章节摘要会处理整本书吗？

不会。它只发送当前选中的章节。

### 为什么生成结果没有自动写进正文？

为了避免模型输出不合适时污染正文。必须先检查候选正文，再点击接受。

### 浏览器调用接口失败怎么办？

如果错误和跨域有关，说明接口服务不允许浏览器直接访问。可以使用桌面版，或后续加一个本地代理服务。

### 思考模型输出 `<think>` 怎么办？

工具会过滤 `<think>...</think>`，不会写入摘要或续写正文。
